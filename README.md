<h1 align="center">Warit Auto Setup</h1>

<p align="center">ตั้งค่า Windows หลังลงเครื่องใหม่ จัดการโปรแกรม ไดรเวอร์ และ Windows Update จากหน้าต่างเดียว</p>

## เริ่มใช้งาน

1. ดาวน์โหลดโปรเจกต์จากปุ่ม **Code → Download ZIP** บน GitHub แล้วแตกไฟล์
2. ถ้ามีตัวติดตั้ง ให้สร้างหรือวางโฟลเดอร์ `payloads\` ไว้ข้าง `Start-AutoSetup.vbs` แล้วจัดไฟล์ตาม [config.json](config.json)
3. ดับเบิลคลิก `Start-AutoSetup.vbs` แล้วยืนยันสิทธิ์ผู้ดูแลระบบ หากเปิดไม่สำเร็จ ให้ใช้ `Start-AutoSetup.bat` เพื่อดูข้อความผิดพลาด
4. กด **ตรวจ Payload** แล้วเลือกงานที่ต้องการ กด **ดูคิวก่อนเริ่ม** เพื่อตรวจลำดับงาน รายการที่ข้าม และเงื่อนไขรีสตาร์ท จากนั้นกด **เริ่มงาน**

> GitHub มีซอร์สของแอปและไฟล์ตั้งค่า ส่วน `payloads/` เก็บแยกไว้ในเครื่อง เปิดแอปและใช้ Windows Update ได้ก่อนเตรียมตัวติดตั้ง

## เลือกงานในแอป

| งาน | สิ่งที่ทำได้ |
| --- | --- |
| สเปกเครื่องและดิสก์ | ดูข้อมูล Windows, CPU, RAM, GPU และดิสก์ รวมถึงจัดสรรพื้นที่ Data |
| โปรแกรมและ Runtimes | เลือกตัวติดตั้ง เพิ่มรายการ และกำหนดลำดับขั้นตอน |
| ไดรเวอร์และ Windows Update | ตรวจหาไดรเวอร์ที่ขาดและจัดการอัปเดตที่ Windows เสนอ |
| Windows และ Office | ตรวจสถานะสิทธิ์ เปิดหน้าการเปิดใช้งาน และติดตั้ง Office จาก Microsoft |

## รายละเอียดการใช้งาน

<details>
<summary>ตรวจ Payload</summary>

กด **ตรวจ Payload** เพื่อดูตำแหน่งโฟลเดอร์และไฟล์ตามรายการตั้งค่า รวมถึงตัวติดตั้งที่ขาดหรือมีชื่อที่ตรงกันหลายไฟล์ การตรวจนี้อ่านข้อมูลไฟล์โดยไม่เรียกตัวติดตั้ง สามารถเปิดแอปและใช้งาน Windows Update ได้ก่อนเตรียม Payload

แอปจะแสดงเฉพาะงานที่มีโฟลเดอร์ Payload ของงานนั้น และงานที่ทำได้โดยไม่ใช้ Payload เมื่อเพิ่มโฟลเดอร์กลับมา ให้กด **ตรวจ Payload** เพื่อแสดงงานนั้นอีกครั้งโดยคงตัวเลือกเดิมไว้ระหว่างที่แอปเปิดอยู่

</details>

<details>
<summary>โปรแกรมและ Runtimes</summary>

- กด **โปรแกรมทั่วไป** หรือ **เลือกรายการโปรแกรม…** เพื่อเลือกว่าจะติดตั้งรายการไหน แล้วกด **บันทึก** ตัวเลือกจะใช้เมื่อกดเริ่มงาน กด **ตรวจหาไฟล์ใหม่** เพื่อค้นหา `.exe` และ `.msi` ใน `payloads\Apps` และโฟลเดอร์ย่อยหนึ่งชั้น รายการใหม่ต้องติ๊กเลือกก่อนบันทึก และไฟล์ `.exe` ต้องระบุพารามิเตอร์ติดตั้งเงียบของผู้ผลิต

- กด **เพิ่มโปรแกรม…** เพื่อสร้างรายการติดตั้งอัตโนมัติ เลือกหมวด **โปรแกรมทั่วไป** หรือ **โปรแกรม Crack** และเลือกไฟล์หลัก `.exe`, `.msi`, `.cmd` หรือ `.bat` ไฟล์ EXE จะเริ่มที่โหมด **Silent** และต้องระบุพารามิเตอร์ของตัวติดตั้ง ส่วน MSI ใช้ `/qn /norestart` อัตโนมัติ ไฟล์ CMD และ BAT ใช้โหมด **รันผ่าน CMD**

- กด **+ เพิ่มขั้นตอน** เพื่อเพิ่มไฟล์ `.reg`, `.cmd` หรือ `.bat` แล้วเลื่อนขึ้นหรือลงเพื่อจัดลำดับเทียบกับไฟล์หลัก กด **เพิ่มในรายการ** แล้วกด **บันทึกการเลือก** เพื่อคัดลอกไฟล์ที่เลือกเข้า `payloads\Apps` ผลของแต่ละขั้นและสรุปผลจะอยู่ใน **Logs** หากขั้นตอนใดล้มเหลว ระบบจะหยุดก่อนทำขั้นตอนถัดไป

- งาน **โปรแกรมทั่วไป (Apps)** ใช้โหมดเงียบเมื่อกดเริ่มงาน: Format Factory 5.22.0.0 เรียก `INSTALL.cmd` ในโฟลเดอร์ของแพ็กเกจ และ PhotoScape 3.7 เรียก `PhotoScapeSetup_V3-7.exe /S` ไฟล์ `.exe` ที่ไม่ได้กำหนดพารามิเตอร์จะถูกข้ามพร้อมบันทึกเหตุผล (รวมตัวติดตั้งเว็บ Adobe AIR ที่มีอยู่)

- เมื่อเลือกงาน **Runtimes** หรือ **โปรแกรมทั่วไป** หากไม่มีตัวติดตั้งบางรายการ โปรแกรมจะข้ามเฉพาะรายการนั้นและบันทึกใน Log ถ้าพบตัวติดตั้งตรงกันหลายไฟล์ โปรแกรมจะหยุดแทนการสุ่มเลือกไฟล์

- ใน `payloads\Runtimes` ให้เก็บไฟล์ CAB ของ DirectX ไว้ข้าง `DXSETUP.exe` สำหรับติดตั้งออฟไลน์ ส่วน .NET Framework 3.5 บน Windows 11 26H1 ขึ้นไปใช้ `DotNet35Setup.exe` และ Windows รุ่นก่อนหน้าเปิดฟีเจอร์ผ่าน DISM โดยใช้ Windows Update หรือโฟลเดอร์ `sxs` จากสื่อ Windows รุ่นเดียวกันที่วางไว้ใน `payloads\Runtimes`

</details>

<details>
<summary>ไดรเวอร์, Windows Update และดิสก์</summary>

- แท็บไดรเวอร์ตรวจอุปกรณ์ที่ขาดไดรเวอร์และค้นหาแพ็กเกจจาก Windows Update โดยไม่ติดตั้ง หากต้องการติดตั้งให้เลือกงานไดรเวอร์แล้วกดเริ่ม แอปจะเลือกไดรเวอร์ที่แนะนำหรือที่ตรงกับอุปกรณ์ที่ขาด และไม่รีสตาร์ทเองในเฟสไดรเวอร์

- งาน **Windows Update** ค้นหาอัปเดตปกติ อัปเดตเสริม และไดรเวอร์จากแหล่งที่ Windows กำหนด Log แสดงเปอร์เซ็นต์ดาวน์โหลดแยกตามรายการ หากต้องรีสตาร์ท แอปจะทำงานที่เลือกให้เสร็จก่อนรีสตาร์ทอัตโนมัติ แอปจะตรวจต่อเมื่อเข้าสู่บัญชีเดิม และจบเมื่อค้นหาแล้วไม่พบรายการที่เสนอ หากรายการที่เหลือต้องให้ผู้ใช้ตอบหรืออัปเดตล้มเหลว ให้ดู Log

- งานแบ่งพาร์ติชันให้เลือกสัดส่วน Data ก่อนเริ่ม โปรดสำรองข้อมูลไว้ก่อน ถ้ามี Volume Data บนดิสก์ Windows อยู่แล้ว แอปจะใช้ Volume เดิมโดยไม่แบ่งใหม่

</details>

<details>
<summary>Windows และ Office</summary>

- ลิ้นชัก **การเปิดใช้งาน** แสดงสถานะการติดตั้ง Office และสถานะสิทธิ์ Windows

- ปุ่ม **ดาวน์โหลดและติดตั้ง Office** ติดตั้ง Office Professional Plus 2024 Retail แบบ 64 บิต ภาษาไทยจาก Microsoft ต้องเชื่อมต่ออินเทอร์เน็ต หากดาวน์โหลดเครื่องมืออัตโนมัติไม่ได้ ให้แตก [Office Deployment Tool จาก Microsoft](https://www.microsoft.com/en-us/download/details.aspx?id=49117) แล้ววาง `setup.exe` ใน `payloads/Office`

- เปิดใช้งาน Office ด้วยสิทธิ์ Retail ที่ตรงรุ่น และตรวจสถานะที่ **File > Account** ในแอป Office ตัวติดตั้งไม่ถอน Office รุ่นเดิมอัตโนมัติ

- ปุ่ม **เปิดใช้งาน Windows ใน Settings** เปิดหน้าของ Windows เพื่อใช้สิทธิ์ดิจิทัลหรือคีย์ที่ตรงรุ่น ลิ้นชักยังแสดง Edition ช่องทางคีย์ และผลตรวจในเครื่องโดยไม่เปิดเผยคีย์ การพบคีย์ OEM ไม่ได้แปลว่า Windows รุ่นที่ติดตั้งใช้คีย์นั้นอยู่

- ในหัวข้อ **เครื่องมือเสริม (TOOL)** ปุ่ม **Office Tool Plus** เปิด `payloads/Office Tool/Office Tool Plus.exe` เมื่อมีไฟล์ใน Payload ส่วนปุ่ม **ACTIVATE MAS** เปิด `payloads/MASMAX/MAS_AIO.cmd` ในหน้าต่างแยกด้วยสิทธิ์ผู้ดูแล โปรดตรวจสอบสคริปต์ก่อนใช้งาน

</details>

<details>
<summary>งานจากแพ็กเกจเฉพาะ</summary>

- งาน **Printer Error 709** คัดลอกโฟลเดอร์ `payloads/+แก้ Code Error Printer` ไปที่ `%ProgramData%\WaritAutoSetup` แล้วรัน `1.gpedit.bat` → นำเข้า `2.RPC.reg` → รัน `Set-SmbClientConfiguration -RequireSecuritySignature $false` ด้วยสิทธิ์ผู้ดูแล โดยไม่ตรวจเครื่องพิมพ์จริง หากขั้นตอนใดล้มเหลว จะบันทึกและข้ามขั้นตอน Printer ที่เหลือ การไม่บังคับ SMB signing ลดการป้องกันการเชื่อมต่อ SMB ขาออก

- งาน **FOXIT PDF Editor Pro** ไม่ถูกเลือกไว้ล่วงหน้า เมื่อเลือกแล้วจะรัน `INSTALL (Run ADMIN).cmd` ใน `payloads/++Foxit PDF Editor Pro` ด้วยสิทธิ์ผู้ดูแล และรอให้สคริปต์จบก่อนเริ่มงานถัดไป โปรดตรวจสอบสคริปต์และไฟล์ในแพ็กเกจก่อนใช้งาน

- งาน **ACDSee Photo Studio Ultimate 2027** ไม่ถูกเลือกไว้ล่วงหน้า ต้องมี 7-Zip (ติดตั้งได้จากงาน Apps) เพื่อแยก MSI และส่วนเสริมจากแพ็กเกจ ACDSee จากนั้นตรวจลายเซ็นและติดตั้งแบบเงียบโดยไม่เปิดวิซาร์ด เมื่อยืนยันว่าติดตั้งแล้วจึงรัน `Host.cmd` แล้วนำเข้า `LL.reg` ถ้าติดตั้งอยู่แล้วจะข้ามเฉพาะตัวติดตั้ง เมื่องานสำเร็จจะบันทึก `ลงhost กับ ll ให้ acdsee แล้ว`

</details>

## สร้าง ZIP และอัปเดตเฉพาะแอป

สร้าง ZIP สำหรับแจกเฉพาะตัวแอปด้วยคำสั่งนี้จากโฟลเดอร์โปรเจกต์

```powershell
powershell.exe -NoProfile -ExecutionPolicy RemoteSigned -File .\Build-AppZip.ps1
```

ไฟล์ที่ได้คือ `dist\Warit-AutoSetup-App.zip` ภายในมีตัวแอป โมดูล และ `config.json` ส่วน `payloads\` เก็บไว้แยกต่างหาก

1. ปิด Auto Setup และสำรอง `config.json` หากเคยแก้การตั้งค่า
2. แตก ZIP ทับในโฟลเดอร์เดิมที่มี `Start-AutoSetup.bat` และ `payloads\` อยู่แล้ว เลือกแทนที่ไฟล์ของแอป แล้วนำการตั้งค่าที่สำรองไว้ไปรวมกับ `config.json` รุ่นใหม่
3. เปิด `Start-AutoSetup.vbs` เพื่อใช้ payload เดิม หากอัปเดตตัวติดตั้ง ให้เปลี่ยนเฉพาะไฟล์ที่เกี่ยวข้องใน `payloads\` และตรวจว่าชื่อไฟล์ตรงกับ `config.json`

สำหรับเครื่องใหม่ ให้วางโฟลเดอร์ `payloads\` ไว้ข้าง `Start-AutoSetup.vbs` หลังแตก ZIP

## ทำ Windows Update ต่อหลังรีสตาร์ท

- เมื่อ Windows Update แจ้งว่าต้องรีสตาร์ท แอปจะบันทึกสถานะและตั้งงานชั่วคราวสำหรับบัญชีเดิม เมื่อรีสตาร์ทแล้วเข้าสู่บัญชีนั้น แอปจะเปิดเพื่อทำเฉพาะ Windows Update ต่อ
- แอปเปิดเองได้ครั้งเดียวต่อการบูต หากอัปเดตล้มเหลว ให้เปิด Start-AutoSetup.vbs เพื่อลองใหม่ เมื่อค้นหาสำเร็จและไม่เหลืออัปเดต แอปจะลบงานชั่วคราว
- หากเคยตั้งทางลัด Autorun รุ่นเก่า แอปจะลบทางลัดของโปรเจกต์นี้เมื่อทางลัดเรียกแอปรุ่นใหม่ หรือรัน Install-Autorun.ps1 เพื่อลบทางลัดทันที
